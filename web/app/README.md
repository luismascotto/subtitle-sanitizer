# Subtitle Sanitizer · Capacitor app

Minimal SPA + [Capacitor](https://capacitorjs.com/) shell for the Go WASM sanitizer. Uses **Vite** to bundle Capacitor plugins and **vanilla JS** for the UI — a small but realistic mobile setup.

## Prerequisites

- [Node.js](https://nodejs.org/) 20+
- [Go](https://go.dev/) (same as the main repo)
- **Android:** [Android Studio](https://developer.android.com/studio) + SDK
- **iOS (macOS only):** Xcode

## Quick start

```bash
cd web/app
npm install
npm run cap:sync      # build WASM + Vite bundle + sync native projects
npm run cap:android   # open Android Studio
```

Browser preview:

```bash
cd web/app
npm run serve         # builds WASM + Vite, then serves dist/
# or, for dev with hot reload:
npm run build:wasm    # once, or when WASM changes
npm run dev           # http://localhost:5173
```

Do **not** run plain `npx serve` from the repo root — there is no `index.html` there (404). The Capacitor app must be served via Vite from `web/app/`.

## Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Vite dev server |
| `npm run build:wasm` | Build `sanitize-go.wasm` and copy to `public/` |
| `npm run build` | Vite production build → `dist/` |
| `npm run build:all` | WASM + Vite |
| `npm run cap:sync` | Full build, then `cap sync` |
| `npm run cap:android` | Open Android Studio |
| `npm run preview` | Serve existing `dist/` (run `build:all` first) |
| `npm run serve` | Build everything, then serve `dist/` |

## Project layout

```
web/app/
  index.html              # Vite entry
  src/
    main.js               # UI + Capacitor save/share
    wasm.js               # WASM loader
    default-config.js     # default rules JSON
    app.css               # mobile-friendly styles
  public/                 # WASM artifacts (generated)
  dist/                   # Vite output → Capacitor webDir
  capacitor.config.json
  android/                # generated by `cap add android`
```

## Native vs browser

- **Browser:** Save triggers a file download.
- **Native:** Save writes to Documents via `@capacitor/filesystem`, then opens the share sheet via `@capacitor/share`.

## Typical mobile workflow

1. Edit UI in `src/` or `index.html`.
2. `npm run cap:sync`
3. Run from Android Studio (emulator or device).

**Live reload on device:** run `npm run dev -- --host`, note your LAN IP, and add to `capacitor.config.json`:

```json
"server": { "url": "http://192.168.x.x:5173", "cleartext": true }
```

Remove `server.url` before release builds.
